# Netflix-Data-Analysis

## 📊 Netflix Analysis Dashboard

## 🎯 Project Overview

This project focuses on analyzing Netflix's vast collection of Movies and TV Shows to gain insights into content distribution, country contribution, audience ratings, and yearly trends. The dashboard was created using Microsoft Power BI to make the analysis interactive, visual, and data-driven.

## 📁 Dataset

The dataset used is Netflix Titles Dataset, which contains details such as:

- Title
- Type (Movie / TV Show)
- Country
- Release Year
- Rating
- Duration
- Genre (Listed In)
- Description

Data was cleaned and transformed in Power Query


## 📈 Key Insights

- Netflix content is available across 86 countries.
- There are over 6,000+ Movies and 2,600+ TV Shows.
- The United States and India contribute the most titles.
- The majority of content is rated TV-MA and TV-14.
- Movies form about 70% of total content, while TV Shows make up 30%.
- Steady increase in Netflix content releases over the years.

## 🧠 KPI Metrics

- Total Movies - 6,126
- Total TV Shows - 2,664
- Number of Countries - 86
- Total Genres - 513
- Latest Release Year	2021

## 📊 Visuals Included

- KPI Cards: Total Movies, Total TV Shows, Countries, Genres
- Pie Chart: Content by Type
- Bar Chart: Titles by Country
- Column Chart: Titles by Rating and Type
- Donut Chart: Titles by Country and Year
- Slicers: Country, Rating, Type, Release Year, Title

## 🧩 Tools Used

- **Microsoft Power BI** for visualization and dashboard creation
- **Power Query** for data cleaning and transformation
- **DAX** for calculated measures and KPIs

## 💡 Conclusion

This dashboard provides a complete overview of Netflix’s global content trends. It helps understand which countries contribute the most, what type of content dominates, and how ratings are distributed — giving valuable business and entertainment insights.

## 🚀 How to Use

- Download the .pbix file
- Open in Power BI Desktop
- Interact with slicers to explore insights by year, country, or rating
